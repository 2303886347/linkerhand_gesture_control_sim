# linkerhand_calibration

通过 Qt 上位机显示 MediaPipe 标注画面，并由用户主动控制各姿态的采样节奏。
生成属于当前用户、摄像头和视角的重定向 YAML，且不会覆盖仓库默认配置。

```bash
ros2 launch linkerhand_bringup calibration_gui.launch.py
```

当前阶段已提供：

- 型号、手侧和摄像头选择，以及感知管线连接、骨架画面和实时检测状态。
- 张开手掌、自然握拳、拇指收拢、拇指展开四个姿态的独立手动采样。
- 默认 2 秒采样进度、取消、重新采样和失败时保留旧结果。
- 目标手、手侧、置信度、整手可见性、有效帧数、有效率和角度稳定度检查。
- 采样结果使用中位数，稳定度使用 P90-P10；O6 四指采用 35% MCP + 65% PIP。
- 四姿态联合关节范围检查和只读结果表。
- 配置名称、默认目录扫描、更新当前配置和另存为新配置。
- 默认目录之外的个人 YAML 导入；型号和手侧不匹配时拒绝加入当前列表。
- 配置元数据包含摄像头、采样质量阈值和四姿态统计，文件仍可直接作为 ROS 2
  `parameters_file` 使用。
- 使用选中的个人配置一键启动单手 RViz 或 Gazebo 验证。
- 验证前释放 GUI 摄像头，停止验证后清理整组进程并按原状态恢复连接。

采样成功后界面只选中下一姿态，不会自动开始下一次采样。高级设置可以修改采样
时长、置信度、最少有效帧、最低有效率和最大允许波动角度。

个人配置默认目录：

```text
~/.config/linkerhand_gesture_control/calibration
```

“生成配置”在默认目录创建新文件；选择已有配置后可以更新覆盖，也可以使用“另存为
新配置”选择其他路径。仓库中的 L30/O6 默认 YAML 始终作为只读模板使用。

选择一份已保存配置后，可以点击“RViz 验证”或“Gazebo 验证”。GUI 会先释放当前
标定摄像头，再将相同设备和个人 YAML 交给单手仿真 launch。验证结束请点击 GUI 的
停止按钮；如果验证前摄像头已连接，停止后会自动恢复连接。完整 launch 日志在启动
GUI 的终端中查看。
